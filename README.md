# Commercial-Banking-Risk-Fraud-Analytics
📌 About the Project

This project features a multi-page, interactive Power BI dashboard aimed at assessing risks in commercial banking operations, analyzing transaction volumes, and detecting fraud (anomaly detection). The dashboard is designed to monitor the health of the credit portfolio and facilitate data-driven strategic decision-making.

📊 Key Features & Metrics

Credit Risk Indicators: Assessment of customer credit scores, solvency, and risk levels.

Transaction Volumes: Dynamics of monthly and annual money turnover, along with segment-based analysis.

Fraud & Anomaly Detection: Visual monitoring of suspicious operations and unusual transactions.

Interactive Analysis: In-depth data exploration by time periods, branches, or customer segments (utilizing Drillthrough and custom Tooltips).

🛠 Technologies Used

Microsoft Power BI: Core visualization and dashboard design.

DAX (Data Analysis Expressions): Creation of complex financial calculations and time-intelligence metrics.

Power Query: Data cleaning, formatting, and ETL (Extract, Transform, Load) process optimization.
